## [1.0.0] - 2026-01-01

First public release.

### Added

- Node-based editor for 2D and 3D graphs with typed pins, subgraphs, comment frames, undo/redo and a command palette.
- Procedural texture nodes: generators, filters, colour tools, curves and gradients, UV, normal and island tools.
- Mesh and spline nodes: spline editing gizmos, sweeps, scattering, copy-to-points, mesh attributes, GLB / glTF / OBJ import.
- Simulations: 2D fluid, vector fields, motion vectors, reaction–diffusion, waves, burn front and lightning.
- Timeline with keyframes, flipbook baking, seamless loops and vertex-animation-texture export.
- Tileable output support across the node set.
- Export of PNG, TGA, OpenEXR, Radiance HDR and DDS images; GLB, glTF, OBJ and PLY meshes; flipbook sheets with JSON sidecars;
  presets for Unreal Engine, Unity and Godot; tile-by-tile rendering for large images.
- Docking user interface with dark and light themes, custom accent colour and saved layouts.
- English and Persian (right-to-left) interfaces.
- Memory-budgeted GPU engine with device-loss recovery, adaptive preview, safe mode and a GPU diagnostics screen.
- 22 sample projects, in-app help with the node reference, and a Vitest suite.
- Project documentation, MIT license, GitHub Actions for CI, GitHub Pages deployment and releases.
