# Keyboard shortcuts

Live list in the app: **Ctrl+/** (Help → *Keyboard shortcuts*). On macOS, **Ctrl** is **Cmd**. Everything can be rebound (Settings → *Keyboard shortcuts*).

| Shortcut | Action |
|---|---|
| Ctrl+K | Command palette |
| Space / right-click (graph) | Add node |
| Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z | Undo / Redo |
| Ctrl+N / O / S | New / Open / Save project |
| Ctrl+I | Import file |
| Ctrl+D | Duplicate selection |
| Delete / Backspace | Delete selected nodes |
| B | Toggle bypass |
| Ctrl+G | Make subgraph (comment frame: Ctrl+Shift+G) |
| Alt+↓ | Enter subgraph |
| Ctrl+Shift+A | Deselect all |
| Alt+F | Float / dock the focused panel |
| Ctrl+Shift+H | Start screen |
| Ctrl+, | Settings |
| F1 | Help & node reference |
| F3 | Performance HUD |
| F11 | Fullscreen |
| Ctrl+Shift+S | Save as |
| Ctrl+A | Select all nodes |
| Ctrl+= / Ctrl+- / Ctrl+0 | Interface scale: larger / smaller / reset |
| Space (when the graph editor is not focused) | Play / pause the timeline |
| Alt+← / Alt+→ | Step one frame back / forward |
| Alt+Shift+← / Alt+Shift+→ | Previous / next keyframe |
| Shift+Home / Shift+End | Go to the first / last frame |
| K | Key the animated parameters of the selected node |
| Shift+K | Toggle auto-key |

Some bindings depend on the focused panel; the in-app list is authoritative.
