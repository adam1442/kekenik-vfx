# Getting help

- **Using the app**: start with the [User Guide](docs/USER_GUIDE.md), the [node reference](docs/NODE_REFERENCE.md) and
  [keyboard shortcuts](docs/KEYBOARD_SHORTCUTS.md).
- **GPU not detected, black viewport, memory problems**: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- **Questions and ideas**: use [GitHub Discussions](https://github.com/adam1442/kekenik-vfx/discussions) if enabled, otherwise open an issue.
- **Bugs**: open an [issue](https://github.com/adam1442/kekenik-vfx/issues/new/choose) and paste the GPU diagnostics
  (GPU Diagnostics screen → *Copy diagnostics*).
- **Security**: see [SECURITY.md](SECURITY.md).
- **Contact the maintainer**: adam1442, hossein.r.1442@gmail.com. This is a volunteer project, so replies may take a while.
